# 墨灵 MoLing

> 版本：v2.2.0 · 2026-11-26

像聊天一样作图 —— 可接入任意 OpenAI 兼容 API 的 Windows 桌面端 AI 绘图工具。

墨灵把 AI 绘图做成聊天：描述你想要的画面，模型逐轮生成，上下文持续累积。它不绑定任何服务商，填入任意 OpenAI 兼容的 API 地址、模型与 Key 即可使用。

## 功能亮点

- **聊天式文生图**：逐轮生成、保留完整会话，可随时复用历史参数
- **任意服务商**：OpenAI 兼容接口、自定义模板与 Mock 调试，支持多 Key 自动切换、代理与 SOCKS5
- **多轮改图**：参考图随请求上送，支持局部重绘、AI 消除、扩图、换背景、放大与风格转换；内置离线智能蒙版
- **任意角度旋转**：基础编辑支持 −180° ~ 180° 自由旋转与自动拉直（±15° 投影估角，裁剪互斥），全部本地像素处理、零计费
- **画布撤销与关闭确认**：`Ctrl Z` / `Ctrl Shift Z` / `Ctrl Y` 撤销重做（仅节点与连线，最多 50 步，平移缩放不入栈）；有未保存改动时关闭窗口先确认
- **AI 修图台（v2.1.0）**：一键优化 / 美颜 / AI 消除 / 一句话改图 / 换背景 / 高清 / 扩图 / 裁剪调色 / 风格 / 局部重绘 / 多区域共 11 个动作，步骤链可回退；一键优化、美颜、裁剪调色与纯色渐变换背景纯本地合成、零计费
- **GIF 动图（v2.0.0）**：接 GPT-Image-2.6 的 GIF 输出，生成后可在时间轴里换序 / 改时长 / 倍速 / 压缩，导出微信表情包与 PNG 序列，支持单帧修复
- **画布工作区**：作品拖入无限画布排布、缩放、连线，节点可直接进入编辑；v2.0.0 增加节点内图层栈与多区域分区重绘
- **计费防护**：每次请求留痕，超时 / 断连等模糊失败标「可能已计费」且绝不自动重发，可在请求记录里找回或标记放弃
- **画廊与批量队列**：时间线浏览、筛选与对比、打包导出；队列支持 1–4 全局并发、每服务商 1–2 并发与逐条重试
- **桌面原生体验**：无边框窗口、墨纸印主题与内置字体、中英双语、命令面板与全局快捷键
- **本地优先**：图片与数据存于本机，API Key 使用 AES-256-GCM 加密保存

## 下载与安装

前往 [Releases](https://github.com/2426758093/moling/releases/latest) 下载 Windows x64 安装包：

1. 运行 `moling_<版本>_x64-setup.exe` 完成安装；
2. 在「设置 → 服务商」填写 API 地址、模型与 Key；
3. 回到会话，直接描述你想要的画面。

应用支持应用内检查并安装更新。

## 系统要求

- Windows 10 / 11 x64
- 自备任意 OpenAI 兼容绘图 API 的访问凭证（应用不内置 Key，也不代理任何服务）

## 技术栈

Tauri 2（Rust）· React 19 · TypeScript · Vite · Tailwind CSS 4 · Zustand · SQLite

## 本地开发

需要 Node.js ≥ 22.12、pnpm ≥ 11 与 Rust 工具链（版本分别由 `.nvmrc` 与 `rust-toolchain.toml` 固定）。

```bash
pnpm install
pnpm tauri dev
```

构建安装包：

```bash
pnpm tauri build --bundles nsis
```
